# MVP File Format

MVP files are markdown documents with the following structure. All sections are
required unless noted otherwise.

```
# MVP: <name>

## Problem (Maximally Valuable Problem)

<the specific problem being tested, stated in terms of observable behavior>

## Hypothesis

<testable statement about revealed preference>

## Threshold Test

- **Pass:** <specific quantitative threshold>
- **Fail:** <everything below the pass threshold>
- **Rationale:** <why this threshold was chosen>

This threshold was set BEFORE the experiment. The post-test question is not
"did we pass?" — the threshold answers that. The question is "what does the
outcome mean, and what do we do next?"

## Key Assumptions

- <assumption 1>
- <assumption 2>

## Proposed Experiment

- **Method:** <experiment type>
- **Audience:** <who to test with and how to reach them>
- **What to measure:** <observable behaviors>
- **Timeline:** <how long to run>

## Action Plan

1. <step>
2. <step>

## Risks and Mitigations

- <risk>: <mitigation>
```
